# 🔐 Random Password Generator

## 📌 Project Overview
The Random Password Generator is a Python application that creates secure and random passwords based on the user's preferred password length. Users can also choose whether to include special characters for stronger password security.

This project was developed as **Project 3** during the **DecodeLabs Python Programming Internship**.

---

## 🎯 Features
- Generate passwords of any desired length
- Option to include or exclude special characters
- Includes uppercase letters, lowercase letters, and digits
- Input validation for password length
- Generate multiple passwords in one session
- Easy to use through the command line

---

## 🛠 Technologies Used
- Python 3
- random module
- string module

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python random_password_generator.py
```
